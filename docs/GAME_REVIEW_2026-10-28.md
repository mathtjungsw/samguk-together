# 삼국 · 함께 천하 전체 검토 — 친구들과 즐기는 소규모 게임

검토일: 2026-10-28. 기준 소스: `af430b0` 및 실제 운영 화면. 단계: **분석·제안이며 구현이나 배포 계획의 승인으로 취급하지 않는다.**

## 1. 판단 기준과 총평

사용자가 명시한 목적은 출시가 아니라 친구 10~15명이 틈틈이 함께 즐기는 것이다. 짧게 접속해 상황을 파악하고, 한두 번 행동하고, 친구들과 결과를 이야기할 수 있는 경험을 우선한다.

현재 게임은 이 목적에 필요한 핵심 요소를 이미 갖췄다. 영토 확장, 주사위의 변동성, 이름 있는 장수의 희소성, 장수 배치와 특기, 공통 채팅, 지난 시즌의 지도·순위가 연결돼 있다. 다음 개선은 새 콘텐츠를 크게 늘리기보다 **이미 있는 정보를 찾고 이해하는 수고를 줄이는 것**이 효과적이다.

PC는 지도·명령·채팅이 분리돼 좋아졌다. 남은 큰 불편은 여러 도시의 상태를 하나씩 찾아야 하는 점, 부재 중의 내 전투를 찾기 어려운 점, 휴대폰에서 지도와 명령·채팅을 오가는 거리다. 시각 디자인의 분위기는 일관적이지만 작은 글씨와 반복 설명 때문에 핵심 상태가 묻히는 부분이 있다.

## 2. 살릴 장점

- **단순한 기본 흐름:** 충원 → 병력 선택 → 인접 영토 공격/이동. 별도 재화나 시설 관리가 없어 진입 부담이 작다.
- **친구들과 공유할 사건:** 장수 영입, 주사위 역전, 군주 전사·부활, 영토 쟁탈이 대화 소재가 된다.
- **배치의 의미:** 무장 효과와 최대 2명의 전투 특기, 자동 담당, 장수 독립 이동 때문에 숫자만 모으는 것 이상의 선택이 있다.
- **최근 전투 개선:** 점수 차에 따른 승자 피해, 접전 패배 장수 생존, 12·14·16 정원은 이미 적용됐다. 이번 검토에서 새 요구로 반복하지 않는다.
- **이미 있는 편의:** 목적지에 맞춘 최대 이동, D4와 장수 교환, 장수 목록에서 위치 확인·이동, 대기시간 표시, PC 채팅 분리.
- **규모에 맞는 운영:** GitHub Pages와 Firebase 구조를 유지할 수 있다. 명령 중복 방지·충돌 재시도·연결 끊김 대응·배포 전 검증이 이미 있다. 이번 검토에서 서버 교체를 추천할 근거는 찾지 못했다. 실제 무료 한도 여유는 사용량 측정 없이 단정하지 않는다.

## 3. 먼저 추천하는 사용성 개선

### A. ‘내 도시’ 목록과 지도 바로 이동 — 우선

현재 선택 전 군령 화면은 ‘내 영토를 고르세요’ 안내가 중심이다. 내 장수 목록에는 위치 이동이 있지만 병사만 있는 도시까지 포함한 도시 현황 목록은 없다.

추천하는 작은 구성:

- 내 도시 이름, 병력/정원, 영토 행동 대기, 다음 충원.
- `전체 / 영토 행동 대기 해제 / 충원 정지 / 다른 군주와 인접` 정도의 필터.
- 도시를 누르면 기존 지도 중심 이동과 명령 패널 선택을 함께 실행.
- 도시의 행동 대기가 끝났다는 것과 실제 병력이 출전할 수 있다는 것을 구분. 잔류 1명, 병력 개별 대기, 목적지 조건까지 확인하지 않고 ‘공격 가능’으로 단정하지 않는다.

예시: `한중 8/16 · 영토 행동 가능 · 충원 02:10`.

효과: 여러 영토를 가진 친구도 지도를 반복해서 뒤지지 않고 한 번의 행동을 고를 수 있다. 자동 공격이나 행동 예약을 새로 만드는 제안은 아니다.

근거: `src/app.js`의 `renderSide`, `src/map.js`의 `focusTerritory`, `public/index.html`의 지도 도구.

### B. ‘내 소식’과 전투 다시보기 — 우선

현재 전황은 최근 100개 전체 사건을 텍스트로 나열한다. 전투 직후의 상세 주사위 화면은 있지만 전황에서 다시 여는 연결이 없다. 특히 수비자는 접속하지 않은 동안의 패배를 이해하기 어렵다.

추천:

- `내 소식 / 전체`를 나누고 내 공격·수비·영토 상실·장수 영입을 모아 보기.
- 보존된 전투 기록 클릭 → 최종 점수, 주사위, 발동 특기, 전사·퇴각자를 다시 보기.
- 결과 맨 위에는 `누가 누구를 공격했고, 누가 이겼는지`를 먼저 표시. 현재 ‘공격 실패 · 근소승’처럼 승리 등급의 주체를 알기 어려운 문구도 정리.
- 접속 시 ‘마지막 확인 이후 소식’을 작게 요약. 최신 100건 밖의 기록까지 완전하게 복원했다고 표현하지 않는다. 기록이 잘렸다면 ‘보관된 기록 기준’이라고 안내.
- 재열기에는 저장된 결과를 사용하고 주사위를 다시 굴리거나 명령을 다시 보내지 않는다. 현재 군주 이름이 바뀐 경우 과거 기록의 시점도 고려한다.

효과: 패배의 이유가 이해되고 친구끼리 전투 이야기를 하기 쉬워진다. 기본 데이터에 결과가 이미 있어 비교적 작은 범위로 접근 가능하다.

근거: `src/app.js`의 `submit`, `showBattle`, `showHistory`, `renderInfoPanel`; `src/engine.js`의 전투 결과 기록.

### C. 휴대폰의 지도·명령·채팅 이동 줄이기 — 우선

모바일 폭 약 391 CSS px에서 실제 배포 화면을 확인했다. 지도 → 군령 → 채팅 순서로 길게 이어진다. 영안 선택 시 채팅 시작 위치가 페이지 상단 기준 약 1,254px, 전체 높이는 약 1,496px였다. 병력과 펼친 정보에 따라 길이는 달라진다.

첫 단계로는 `지도 / 명령 / 채팅` 작은 바로가기와 선택 도시명을 보여주는 구성이 적당하다. 기존 화면을 유지하면서 해당 위치로 이동하게 해도 왕복 수고를 줄일 수 있다. 반응을 본 후 필요하면 명령판의 높이를 조절하는 방식으로 확장한다.

키보드가 올라온 상태, 브라우저 아래 도구막대, 긴 장수 목록에서 조작 버튼이 가려지지 않아야 한다. PC의 새 3열 배치는 유지할 장점이다.

근거: 실제 모바일 폭 화면 및 `public/readiness-layout.css` 모바일 규칙.

### D. 대기시간은 유지하고 정보의 반복 줄이기 — 다음

요청한 병력별 대기시간은 유용하므로 없애지 않는다. 다만 D4의 ‘개체 준비 완료’가 병사 행과 일정 상자에 중복되고, 장수마다 비슷한 시간 안내가 여러 줄 반복된다. 실제 화면에서도 같은 내용을 반복해서 읽게 된다.

추천 기본 카드 예시:

- 장수: `고순 · D6`, `공격 03:20 · 이동 가능`.
- 병사: `D4 8명 · 준비 5명`, `02:10 뒤 +3명`.
- 서로 다른 제한이 있으면 ‘왜 기다리는지’를 짧게 표시하고, 전체 일정·병사 동반 조건·특기 계산은 펼치기에서 확인.
- 중요 수치와 행동 가능 문구는 크게, 배경 설명과 자동 배정 우선순위는 작게 또는 상세로 이동.
- `개체 준비 완료` 같은 표현은 ‘병사 준비 완료’ 등으로 쉽게 바꾸되 실제 출전 가능 인원과 혼동시키지 않기.

근거: `src/readiness.js`, `src/app.js`의 `roster`, `renderFooter`, `src/officer-ui.js`, 10~11px 보조 글씨를 사용하는 CSS.

### E. 지도의 상태 구분 강화 — 다음

녹색·금색·비단 질감과 성곽 표식은 잘 어울린다. 새 장식을 늘리기보다 다음 구분을 강화하는 편이 낫다.

- 내 영토, 선택 출발지, 선택 목적지, 인접 후보의 테두리와 작은 표식을 일관되게 구분.
- ‘내 영토 중심 보기’를 제공하고, 필요할 때만 영토 행동 대기 해제·충원 정지 등을 지도에 표시.
- 다른 군주의 색을 작은 범례로 확인할 수 있게 하거나 군주 선택으로 소유 영역 강조. 현재 기본 범례는 내 영토와 중립 중심이다.
- 작은 도시명은 확대 수준에 따라 선별 표시하는 기존 방식을 유지. 지도 전체에 상태 배지를 항상 넣어 더 복잡하게 만들지 않는다.
- 사용자가 확정한 지형 보정 없음, 연결 관계, 인접 수는 유지한다.

### F. 친구 대화가 전령 소식에 묻히지 않게 — 다음

D6 알림은 최신 사용자 결정대로 유지한다. 현재 사람 대화와 시스템 소식이 동일한 최신 5개 미리보기·서버 50개에 섞인다. 장수 소식이 많아지면 대화가 빨리 밀릴 가능성이 있다.

추천은 우선 `모두 / 대화 / 전령` 표시 필터와 전령 카드의 간결한 표현이다. **표시 필터는 이미 서버 50개 밖으로 밀려난 대화를 보존하거나 복원하지 않는다.** 보관 개수·정책 변경은 별도 사용자 결정으로 남긴다. 현재 채팅 모달은 새 글이 오면 무조건 맨 아래로 이동하므로, 과거 글을 읽는 중에는 위치를 유지하고 ‘새 메시지’ 버튼을 보여주는 보완도 좋다.

## 5. 게임 균형에서 지켜볼 점

### 영토 수와 장수 획득 기회가 함께 늘어남

기본 충원은 빈자리가 유지되는 도시당 시간당 6회다. 따라서 다른 조건이 같으면 도시 2개와 10개의 기본 추첨 기회는 12회와 60회로 5배 차이다. 도시 정원·무장 효과·이동·전사·이름 고갈에 따라 실제 충원은 달라진다. 장수 분포가 한 군주에게 몰렸다고 곧바로 확률 오류라고 볼 수 없다.

우선은 ‘충원 중인 내 도시 / 정원 도달 도시’와 `D6 생존 수/50 · D8/30 · D12/20` 같은 모집 현황을 보여주면 이해가 쉬워진다. 이미 도감에는 장수별 소유자·미등장 상태가 있으므로 요약을 더하는 정도다.

친구들이 큰 세력을 견제하는 재미를 느끼는지, 늦게 들어온 친구가 할 일이 없어지는지를 실제 플레이로 확인한 뒤 보정 여부를 결정한다. 확률 하향·선두 페널티·후발 보너스를 이번 검토만으로 도입하지 않는다.

### 병력 가득 찬 도시에 정면 공격은 여전히 어려움

장수·특기 없이 D4만 있는 양쪽 만원 도시에서 1명 잔류 후 공격하면 다음과 같다. 현재 순수 주사위 확률 함수를 읽기 전용으로 계산했다.

| 공격 / 수비 D4 수 | 기본 승률 |
| --- | ---: |
| 11 / 12 | 약 11.37% |
| 13 / 14 | 약 11.41% |
| 15 / 16 | 약 11.28% |

이는 공격 90%·동점 수비 승리·1명 잔류를 유지한 결과다. 장수 배치·병력 집중·빈틈 공략을 즐긴다면 의미가 있다. 후반에 모두 만원으로 채운 채 전투를 피한다면 그때 다시 검토할 대상이다. 현재 실제 친구들이 이런 정체를 겪고 있다는 관찰은 하지 않았다.

점수 차 10점 이상의 완승에서는 승자 피해가 없으므로 강한 병력으로 약한 곳을 공략하기 유리하다. 이는 최근 사용자가 정한 방향이다. 한두 번의 기록만으로 공식을 다시 뒤집지 않는 편이 좋다.

야간 휴전·부재 보호는 이전에 사용자가 제외했으므로 이번 새 대기 항목으로 되살리지 않는다. 자동 시즌 종료 조건도 새로 제안하지 않는다.

## 6. 나중에 고려할 작은 재미

친구들이 현재 전투를 즐기고 기본 편의가 안정된 뒤에는 ‘오늘의 접전’, ‘군주 생환’, ‘최대 역전’처럼 전투력 보상이 없는 짧은 명예 기록이 어울릴 수 있다. 새로운 재화·숙제·출석 보상을 만들기보다 이미 벌어진 사건을 재미있게 보여주는 방향이다. 현재 기록만으로 정확히 산출할 수 있는 항목부터 고르고, 하루 전체 기록이 남지 않으면 ‘오늘 전체’라고 단정하지 않는다.

1. 작은 표시·조작 오류: 지도 확대 유지, 승률 극단값, 전투 결과 주체, 채팅 읽던 위치, 현재 규칙 안내 정리.
2. 접속 편의: 내 도시 목록, 내 소식 필터, 저장된 전투 다시보기.
