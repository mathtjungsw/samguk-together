# 이전 명령 경고 복구 · 2026-11-02

사진에 남은 카드는 삭제된 비밀 목표가 아니라 통신 중단 시 명령의 중복 실행을 막는 복구 카드다. 사용자 단말의 원본 저장 요청은 접근할 수 없어 사진만으로 요청 종류를 단정하지 않는다.

## 확인한 코드 결함과 수정

- 서버 성공 응답 후 후속 전황 읽기까지 성공해야 기기 대기 요청을 지웠다. 읽기 실패가 확정 명령을 미확인 상태로 남기던 결함을 수정했다. 성공 응답 즉시 대기를 해제하고 동기화 실패는 별도로 안내한다.
- 실시간 전황이나 재접속에서 동일 군주의 처리 영수증이 확인되면 복구 카드를 자동 정리한다. 영수증이 최근100개 보관 범위 밖이면 같은 시즌의 군주별 명령 순번이 이미 증가했는지 확인한다. 이 경우 재실행 불가만 확정하며 성공했다고 표시하지 않는다.
- 진짜 미확인 명령은 보존하고 수동 확인 시 최신 전황을 먼저 읽는다. 재시도는 기존ID·순번·병력 선택을 그대로 사용한다. 다른 새 명령이나 배경 충원이 요청을 덮어쓰지 않는다.
- 다른 탭의 새 대기 요청과 다른 시즌 요청을 보호한다. 이전 시즌 공격을 새 시즌에 옮겨 재실행하지 않는다.
- 새 주기 조회·DB 경로·서버 규칙 변경은 없다. 기존 동기화 데이터로 자동 확인하고 사용자가 복구할 때만 필요한 읽기를 수행한다.

## 검증

단위336개 통과. 추가12개는 성공 후 화면 읽기 실패, 실제 서버 적용 직후 응답 유실, 중복 호출 방지, 영수증 보관 만료, 수동 복구 선조회, 실패/확정 거절, 동일 요청 재시도, 다른 탭·시즌 보존을 검증한다. 사이트 번들 생성 성공. 로컬 브라우저 연결이 비활성화되어 직접 화면 검증은 수행하지 못했다. 배포 결과는 완료 후 추가한다.
