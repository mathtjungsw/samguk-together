# 새 시즌 첫 참가자 등록 오류 수정

상태: 구현·대상 검증 완료, 배포 진행 중. 적용: 현재 시즌5 및 이후.

## 원인과 수정

Realtime Database는 빈 객체를 저장하지 않는다. 시즌 생성 직후 참가자가0명이면 players/receipts/history 같은 빈 경로가 반환 JSON에서 생략된다. campaignCommand가 등록 전 개인 순번을 확인할 때 raw.players[uid]를 사용해 Cannot read properties of undefined (reading '계정ID') 오류가 발생했다. 오류 후 정산 경로에서도 같은 직접 접근으로 원래 오류를 가릴 수 있었다.

등록 전 순번 확인과 실패 후 정산에서 빈 players 경로를 허용하도록 optional chaining을 추가했다. 첫 등록은 순번0으로 진행하며 등록 성공 뒤1로 증가한다. 기존 참가자·영토·병력·무장·강화·포로와 시즌 시간은 변경하지 않는다. 빈 전장을 임의로 초기화하거나 참가자를 대신 등록하는 운영 데이터 수정은 하지 않는다.

## 재발 방지 검증

- 단위321개 통과. Firebase가 생략하는 빈 경로가 없는 첫 등록→동일 요청 재전송→시작 순번2와, 미등록 사용자의 거절 후 정산을 검사했다.
- 별도 Firebase Admin 통합2개 통과. 실제 에뮬레이터에 빈 시즌을 저장한 뒤 players/receipts가 반환값에서 생략되는 것을 확인하고, 등록·재전송·첫 영토 배정의 원자 저장을 검증했다. 기존 경합·탈출 우선 검사도 유지한다.
- 로그인 오류 메시지에서 보인 계정ID를 사용하지 않고 합성 계정으로 동일 오류를 수정 전 재현했다. 운영 계정으로 시험 가입하거나 영토 배정하지 않았다.

## 배포

접속을 우선 복구하기 위해 campaignOrder 함수를 먼저 배포한다. 이후 사이트·공지 ID와 전체 서버 번들을 일치시키고 전체 채팅/전황/접속 안내를 게시한다. 최종 결과는 완료 후 추가한다.
