# 비밀 목표·토벌령·포로·인연·무장200명 업데이트

상태: 구현·검증·Firebase/GitHub Pages 배포·전체 공지 완료. 적용 시작: **시즌5**. 운영 시즌4의 규칙·병력·무장 명단은 바꾸지 않는다.

## 게임에서 달라지는 점

- 비밀 목표: 개인에게만 공개되는 후보 최대3개 중 하나 선택. 시즌당1회, 완료 시 미등장D6 무작위2명 수령권. 중립 목표가 달성 불가능해지면1회 교체. 보상 무장 부족 시 남은 수령권 보존.
- 토벌령: 개막6시간 이후 활동세력3개 이상, 단독1위30도시 이상이고2위와10곳 이상 차이이면2시간 발동. 실제 점령에D6 무작위1명. 한 토벌령 개인2회·전장6회·도시1회, 시즌 개인4회·같은 상대/도시1회. 종료 후4시간 재발동 대기, 같은 대상 시즌2회.
- 포로: 기존 생존·호위 판정을 모두 거친 패전 고유D6/D8/D12 중 전투당 최대1명을20%로 포획. 포획자별최대3명. D20·이름 없는 병력·희생 호위·강화 전사 제외.
- 처형: 포획 즉시부터 탈출 전까지 가능, 시즌 횟수 제한 없음. 확인창을 거친다. 처형은 전사/처형 통계이며 전투 처치 수에는 포함하지 않는다.
- 강제 등용:30분 후부터 실제 시도 기준10분 간격. 기본D4 비용6/12/20명 + 현재 강화 단계. 성공률40/25/15%. 성공·실패 모두 비용 소모, 도시 행동 소모 없음. 성공 시 같은 병력ID·강화·누적실패·효과 이력 보존,20분 대기.
- 몸값: D6/D8/D12 순D4 4/8/14명. 내 도시최대3곳의 행동 가능한0강D4를 사용하고 각 도시1명 잔류.10분 유효 반환 요청 후 상대가 수락할 때만 양측 병력과 포로를 원자 이전한다. 정원 초과분 복귀 대기.
- 탈출: 포획30~110분에10분마다10%,120분에는 확정 탈출. 정산 지연 시 밀린 판정을 차례로 처리하고 명령보다 탈출을 먼저 처리한다. 영토/빈자리 없어도 장수는 보호 복귀 대기에 보존한다. AI는 처형·강제 등용하지 않으며 몸값 요청/수락만 처리한다.
- 포로 탭: 내가 잡은 포로/잡힌 내 장수, 확정 탈출 시각·다음 확률 탈출·등용 대기·등급/강화 비용 표시. 포로 이름은 생존 장수로 예약해 중복 출현을 막는다.
- 인연6종: 도원결의/적벽의 호흡/강동의 방패/관문의 계승/연인의 기개/패업의 보좌. 양측 전투 각1개·내정 도시당1개 자동 적용. 자세한 수치는 게임의 장수 능력과 무장200명 표 참고.
- 무장200명: D12 30명/D8 60명/D6 110명. 기존150명 ID 유지, 신규50명. 기존11명 티어·14명 능력 조정. 구시즌은 기존150명/효과2판 유지, 신시즌에만 새 카탈로그/효과3판 적용. 자연 충원 기본90/7/2.5/0.5% 유지. 새 초상은 기존의 공통 대체 초상 사용.

## 저장·비용·운영

시즌5부터 일반/포로/보상 명령은 Google 인증 callable 서버에서 확정한다. 개인 명령 순번, 고정 서버 난수,100개 영수증과 원자 저장으로 재전송/경합 시 재추첨·이중 차감을 막는다. 비밀 목표는 본인만 읽는 별도 경로이며 클라이언트는 수정할 수 없다. 구버전의 시즌5 직접 쓰기는 거부한다.

새 명령의 함수 호출과 서버 DB 읽기는 추가 비용 요인이다. 비용을 이유로 개발을 중지하지 않는다. 새 주기 조회/추가 스케줄러는 없고 기존10분 정산과 명령 시 정산을 사용한다. 전투 상세/지난 시즌 로컬 캐시·작은 전황 요약·필요한 경로 조회를 유지한다.
