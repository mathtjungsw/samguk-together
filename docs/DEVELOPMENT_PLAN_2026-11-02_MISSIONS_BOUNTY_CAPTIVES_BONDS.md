- 친구10~15명의 짧은 접속에 맞춰 직접 선택은 목표1개/포로 협상 정도로 제한한다. 인연은 자동 적용하며 실시간 응답을 강요하지 않는다.

## 2. 1번 — 군주별 비밀 목표

### 2.1 선택과 공개 범위

1. 시즌 최초 참가 후 내 군령에 ‘비밀 목표 선택’ 카드를 표시한다. 기존 출전·이동은 선택 전에도 가능하다.
2. 서버가 현재 상태로 달성 가능한 서로 다른 목표3개를 제시한다. 플레이어가1개를 선택한다. 미선택이면 접속 시 같은 선택지를 보여주며 새로고침으로 다시 추첨하지 않는다.
3. 한 군주·한 시즌에 선택/완료/보상 각1회. 마지막 영토를 잃고 재참가해도 선택·진행·수령 기록을 유지한다. AI에는 목표/보상을 지급하지 않는다.
4. 목표 이름·상세·진행은 본인만 읽는 별도 경로에 저장한다. 전장 전체 구독·채팅·전황·미선택 선택지에 타인의 목표가 포함되지 않게 한다.
5. 완료 후에도 상세 목표를 전체에 자동 공개하지 않는다. 보상으로 병력이 도착하는 공개 효과만 발생하며 별도 목표 시상은 추가하지 않는다.

- 진행은 선택 이후 확정된 사건만 집계한다. 선택 전에 달성한 실적은 소급하지 않되 보유형 목표는 선택 시 이미 완료 상태인 후보를 제외한다.
- 중립 목표를 선택한 뒤 다른 세력이 중립을 모두 점령하는 등 객관적으로 불가능해지면 서버 판단으로1회 교체 가능하다. 진행0으로 초기화하고 새 후보를 고정한다. 단순히 어려워졌다는 이유의 재추첨은 제공하지 않는다.
- 항상3개를 억지로 만들지 않는다. 유효 후보가1~2개면 그 수만 제공하고, 후보0이면 다음 유효 사건 후 다시 판정한다. 초기/중기/막판/늦은 참가 상태에서 최소1개 가능한지 검증한다.

### 2.3 완료·보상

- 사용자 확정 보상: **미등장 D6 무장 무작위2명**. 0강·실패0으로 지급한다. 후보 부족 시 남은D6 수령 슬롯은 보존하고 D4/익명D6로 바꾸지 않는다. 부분 수령·동시 추첨은 최신 개정안을 따른다.
- 완료 시 내 카드에 ‘보상 받기’ 표시. 본인 도시1곳을 선택해 받을 수 있다. 빈자리 부족분은 본인의 기존 복귀 대기 방식에 안전 보관하며 군주 생존 조건을 요구하지 않는다.
- 지급 D6는 수령 후10분 행동·이동 대기. 도시 행동은 소모하지 않는다. 선택 도시가 전투 잠금/소유권 변경이면 미지급 상태로 다시 선택한다.
- 영토0일 때는 수령을 보류하고 재참가 후 받는다. 시즌 종료 뒤 미수령 보상은 소멸하며 다음 시즌으로 이월하지 않는다.
- 완료/수령 요청ID·보상ID를 고정해 여러 창·응답 유실에도1회만 지급한다. 개인 목표 달성을 위해 타인과 도시를 주고받는 행위가 반복 보상으로 이어지지 않게 시즌1회 한도를 유지한다.

## 3. 2번 — 강대국 현상금·토벌령

### 3.1 발동과 종료

- 발동 기본값: 시즌 개막6시간 이후, 영토가 있는 세력3개 이상, **단독1위30영토 이상이며2위보다10영토 이상 많을 때**.
- 사람과 AI 모두 토벌 대상이 될 수 있다. 동률1위에는 발동하지 않는다. AI가 토벌 대상에 대한 일반 공격을 하는 것은 가능하지만 현상금 보상은 사람에게만 지급한다.
- 한 번에 대상1명·기간2시간. 발동 즉시 전체에 대상·종료 시각·보상 한도를 알린다.
- 도중에 대상이 바뀌어도 새1위로 자동 전환하지 않는다. 대상이1위에서 내려가거나2위와 격차가5영토 이하가 되거나 영토0/시즌 종료이면 조기 해제한다.
- 해제 후 전장 전체4시간 재발동 대기. 같은 군주는 시즌 중 최대2번만 토벌 대상이 된다. 다른 대상을 찾으려고 임의 순위를 변경하지 않는다.
- 전투 중 발동한 토벌령은 그 전투에 소급하지 않는다. 관평 선택 대기 중이라면 공격 시작 시 토벌령ID를 보관해 보상 유효성을 판단한다.

### 3.2 보상

- 유효한 토벌령 기간 안에 시작한 공격이 만료 전 최종 확정되고, 실제 대상 소유 도시를 점령한 사람에게 **미등장 D6 무작위1명 수령권**을 지급한다. 도시를 다시 잃어도 확정된 수령권은 유지한다.
- 자동 승리/추가 공격력/방어 약화는 부여하지 않는다. 수비 승리·단순 이동·참가 시 무작위 배치/AI 내부 등장/양도는 점령 보상이 아니다.
- 한 토벌령에서 군주당2회, 전장 전체6회까지. 같은 도시는 한 토벌령에서 최초1회만 보상한다.
- 동일(공격 군주, 대상 군주, 도시)은 시즌 전체1회만 보상한다. 한 시즌에 군주당 토벌 보상 최대D6 4명. 같은 도시를 돌려주며 다른 토벌령에서 다시 받는 반복을 제한한다.
- 지급 경로·대기·정원 초과·시즌 종료·중복 방지는 비밀 목표와 동일한 보상 처리기를 사용한다. 수령권은 시즌 종료 전까지만 사용한다.
- 한 전투에서 비밀 목표와 토벌 보상이 동시에 완료되는 것은 허용하되 각기 고유한1회 지급ID를 사용한다.

### 3.3 판정 순서

- 공격 요청의 이전 전황으로 유효 토벌령을 고정 → 전투 확정 → 점령 보상 판정 → 새 영토 순위로 토벌령 유지/해제 판정 → 시즌 승리 판정.
- 시간 종료가 먼저 도달하면 기존 마감 규칙대로 처리한다. 종료 후 신규 토벌령/보상 수령/보상 지급은 없다. 토벌 대상의72영토 달성을 억지로 유예하지 않는다.

## 4. 6번 — 장수 포로·반환 협상

### 4.1 포로 대상과 확률

- **사람/AI 세력 간 전투의 패자 측 이름 있는 D6·D8·D12만** 포로 후보. D4·익명 동급 병력·D20·중립전·강화 전사·호위로 의도적으로 희생한 장수는 제외한다.
- 기존 관평10초 선택과 모든 호위/특기 탈출/근소 패배 생존·퇴각을 먼저 끝낸다. 그 후에도 전사 예정인 후보 중에서만 포로 추첨한다. 기존에 탈출한 장수를 다시 붙잡지 않는다.
- 추천값: 전투당 최대1명. 후보 중 서버 난수로1명을 고른 뒤 **20% 포획**. 고티어 우선 선별은 하지 않는다. 승자측 손실 장수는 대상이 아니다.
- 포획 측이 이미3명을 억류 중이면 해당 전투에서는 포로 추첨을 하지 않는다. 포로가 될 추가 확률은 전투 생존율을 높이므로 경계 효과와 균형을 별도로 검사한다.
- 서버 난수·전투ID로 추첨을 고정하고 관평 확정 재요청/응답 유실로 재추첨하지 않는다. 포로 여부는 명령 전 예상 승패 확률 자체를 바꾸지 않는다.

### 4.2 보유·위치·통계

- 포로의 소유 군주는 원래 군주로 유지한다. 별도 포로 목록에 포획 군주ID·원소유ID·원병력ID·원래life·포획/탈출 시각·전투ID와 전체 병력 상태를 보관한다.
- 포로는 도시에 실제 주둔하지 않고 주둔 한도를 차지하지 않는다. 공격·수비·내정·인연·강화·직접 이동·재료 사용은 불가하다.
- 무장 이름은 계속 예약해 같은 장수가 다시 충원되지 않게 한다. `heroIndex`에 포로 위치 유형을 추가하고 도시/복귀/포로를 함께 유일성 검사한다.
- 강화 단계·누적 실패·고유 효과 사용 이력·생성 시각·기존 대기를 그대로 보존한다. 포획은 전사/처치로 집계하지 않고 `포획/피포획`만 별도 누적한다.
- 기존 장수 보유 랭킹은 원소유의 포로 장수도 보유수에 포함하되 ‘출전 가능/포로’를 구분해 표시한다. 포획자의 보유 장수·병력수에는 합산하지 않는다. 시즌 우승은 계속 영토 기준이다.

### 4.3 협상과 자동 탈출

- 기본 억류 시간 **2시간**. 포획자는 언제든 무상 석방할 수 있다. 최신 개정에 따라 포획 즉시부터 확정탈출 전까지 무제한 횟수의 처형,30분 뒤부터10분 간격 강제등용 시도를 포함한다. 비용·확률·시도대기·강화추가비용·AI 정책은 개정 문서를 따른다. 장수간 맞교환·임의 몸값 입력은 추가하지 않는다.
- 원소유는 본인 도시 최대3곳과 비용 병사를 선택해 고정 몸값의 반환 요청1개를 낼 수 있다. 추천 몸값: D6는 D4 4명, D8는8명, D12는14명. 행동 가능한0강 D4만 사용하며 강화 병사 자동 소모를 막는다.
- 요청 유효10분, 미응답이면 자동 취소하고 억류는 계속한다. 요청 단계에서 비용을 차감하지 않는다. 요청이 만료돼도 포로의2시간 탈출 시각을 연장하지 않는다.
- 포획자는 수락/거절/무상 석방 선택. 수락 시 서버가 요청 도시 소유권·잠금·준비된 재료·최소 잔류1명을 다시 검사하고 포로 반환과 몸값 이전을 **한 번에 확정**한다. 재료를 썼거나 도시를 잃었으면 실패하며 어느 쪽도 일부 지급/소모하지 않는다.
- 몸값은 원소유의D4를 교환 비용으로 소모하고 포획자에게 같은 수의 새D4로 지급한다. 강화/실패0·10분 대기, 고유 지급ID 사용. 전사/처치 집계 제외, 교환/몸값 수령 통계 분리. 포획자가 받을 도시를 수락 때 선택하며 초과분은 본인 복귀 대기에 보존한다.
- AI 포획자는 유효한 고정 몸값 요청을 자동 수락한다. AI가 포로를 되찾는 경우에는 기존10분 판단 중 본인 안전 후방 도시에서 재료/잔류 충족 시 같은 절차로 요청하고, 부족하면 탈출을 기다린다. AI는 처형과 강제등용을 실행하지 않는다. 별도 AI 성격은 추가하지 않는다.
- 반환·무상 석방·자동 탈출은 원소유가 선택한 본인 도시 또는 자동 안전 도시로 보낸다. 자동 목적지는 전투 잠금이 없는 도시 중 빈자리가 많은 곳, 동률ID순. 빈자리가 없으면 **복귀 대기에 보존**하며 D4를 임의 소모하거나 장수를 전사시키지 않는다.
- 복귀 병력의 행동/이동 대기는 각각 `max(기존 대기, 복귀 확정 시각+10분)`. 강화로 대기를 초기화하거나 포로를 이용해 특기 생애 사용 횟수를 초기화하지 않는다.
- 확률탈출은 포획30분 뒤 최초, 이후10분마다10%,120분에는 확정탈출한다. 탈출 정리는 기존 서버10분 작업과 접속/명령 시 정산에 합친다. 화면의 예정 시각은 정확히 표시하되 미접속 시 실제 배치가 다음 정산까지 최대 약10분 늦어질 수 있음을 설명한다. 만료시각 이후 수락 요청은 거절하고 먼저 탈출을 처리한다.

### 4.4 소멸·재참가·시즌 경계

- 포획 세력이 영토0이 되면 억류 포로를 즉시 석방하고 남은 반환 요청을 취소한다.
- 원소유 영토0이어도 포로를 삭제하지 않는다. 석방/탈출 후 원소유의 대기 목록에 보존하고, 재참가 전에는 무효력 상태로 둔다. 재참가하면 현life에 이어 배치한다. 이는 군주 부활/추가 시작D6 보상을 발생시키지 않는다.
- 현행 마지막 영토 상실 시 복귀 대기를 지우는 경로와 분리하여, **포로 반환으로 보호되는 병력은 그 삭제에 휩쓸리지 않게** 한다. 이 변경은 반환 병력 보존에만 한정하고 일반 복귀 손실 규칙 전체를 임의 변경하지 않는다.
- 시즌 종료 시점의 포로 상태는 최종 랭킹 계산에 고정하고 모든 요청/미지급 몸값을 닫는다. 이전 시즌에서 종료 후 탈출·병력 변경은 하지 않는다. 새 시즌에는 포로·고유 이름 예약·몸값 요청을 이월하지 않는다.
- 재참가/탈출/교환 동시 실행에도 하나의병력ID가 도시·대기·포로에 동시에 존재하지 않아야 한다.

## 7. 구현 구조·저장 권한·통신 절감

### 7.1 공통 상태와 비밀 상태

- 포로/협상은 전장 트랜잭션 안에서 병력·이름 예약·몸값·반환·통계·영수증을 함께 확정한다. DB 루트 전체 트랜잭션은 사용하지 않는다.

### 7.2 서버 명령 경계

- 현재 기본 전투는 클라이언트 계산/저장, AI와 강화/보상은 서버 처리다. 포획 난수와 보상에 연결되는 전투는 새 시즌에서 서버가 계산·확정하도록 확장한다. 화면 계산은 예상 승률용으로 남긴다.
- 새 시즌의 명령 진입점을 기존 순수 엔진을 재사용하는 서버 명령 처리기로 통일해 등록/시작/이동·전투/호위 확정/정산·담당·부활 등 공유 전황 명령을 허용목록으로 검증한다. 구시즌 경로는 보존한다. 세 기능을 클라이언트가 원본 전장에서 임의 제거/증액할 수 없게 한다.
- 임의seed·frozenResult·보상 개수·포로 확률·다른 군주의UID를 클라이언트 입력으로 신뢰하지 않는다. 현재 강화 서버 난수/순번/영수증 방식을 재사용한다. 기존 관평10초 선택은 서버에 고정된 결과로만 확정한다.
- 서버 최초 빈 캐시 트랜잭션 문제를 방지하는 기존 제한 구독 도우미를 재사용한다. 중복/오래된 요청과 충돌을 거부하며 승인된 새 명령만 직렬 확정한다. 종료/잠금/대기를 서버시각으로 검사한다.
- 기능 버전 없는 이전 시즌에는 새 규칙을 강제하지 않는다. 새 시즌에서 구버전 클라이언트 쓰기는 거절하고 새로고침 안내를 제공한다. DB 보안 규칙256KiB 한도를 검사하고 기존 저장 보호를 삭제해 맞추지 않는다.

### 7.3 비용과 정산

- 비밀 목표는 내 경로1개만 구독하고 전장 바뀔 때마다 재추첨/과거기록 읽기를 하지 않는다. 토벌/포로/인연은 기존 전황 구독에 필요한 작은 변경분만 싣는다.
- 타이머는 화면 로컬 카운트다운으로 표시하고 DB초단위 쓰기는 없다. 기존10분 서버 작업/플레이어 명령의 정산에 만료를 통합한다. 새분단위예약·상시 인스턴스는 만들지 않는다.
- 포로 상세/과거 전투는 열 때만 조회하고 기존 로컬 기록 캐시를 재사용한다. 비밀 목표와 미확인 협상은 종료/로그아웃 때 화면에서 제거하고 다른 계정 캐시와 분리한다.
- 포로는 최대200개 고유 장수, 포획군주당3명. 현상금 수령권은군주당최대4, 목표1개. 시즌 내 보상 중복 키는 시즌 종료까지 보존해 정리 후 다시 받는 오류를 막는다.
- 서버 명령 실행과 비밀 경로 구독이 추가되어 함수 실행·DB전송이 늘 수 있다. 기존CPU/최대1/상시0 인스턴스 기본과 변경분 전송을 유지하고, 비용 가능성은 안내하되 개발 중지 조건으로 삼지 않는다.

## 8. 처리 순서와 구현 단계

1. 새 시즌 기능 버전·구버전 차단·서버 명령 어댑터·저장 스키마/보상 공통 처리부터 구현한다.
2. 비밀 목표 선택·진행·수령, 토벌령 조건/해제/중복 제한을 구현한다.
3. 병력 위치에 포로 유형을 추가하고 충원 예약·랭킹·복귀/재참가·강화·정산을 연결한다.
4. 포로 추첨·반환 요청/몸값/석방/탈출·처형·강제등용을 원자 처리하고 관평과 결합한다.
5. 인연 목록·전투/승자피해/내정 함수·예상 승률/AI 평가를 연결한다.
6. 전투 처리 순서: 기존 주사위와고유특기 → 인연 점수 → 승패/점수차 → 승자피해/기존보호/인연보호 → 패자호위·탈출·일반생존 → 포로 → 실제 사망/통계/위치예약 → 점령·비밀성과·현상금 → 토벌해제·시즌종료. 관평 선택은 패자생존 확정 전의 기존 대기 위치를 유지한다.
7. 정산 이벤트는 예정시각순으로 처리한다. 시즌 마감 이후의 충원/포로 탈출/현상금 수령을 최종 기록에 섞지 않는다. 동일시각 탈출 만료와반환은 탈출을 먼저 확정한다.
8. UI·규칙 설명·회귀 검사·로컬 화면 확인 후 서버/규칙/화면을 배포하고 최초 적용 새 시즌을 고정한다. 다음 시즌 생성 시 원자적으로 기능을 켠다.
9. 완료 시 전체 채팅·전황·접속알림에 실제 적용 범위와 개막 시점을 알린다. 임의의 운영 전투·포로·보상 지급으로 검증하지 않는다.
