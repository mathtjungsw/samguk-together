2026-10-28 10:45경 후속 배포: 테스트 시즌은 v4를 유지하고 시즌 1은 개막 즉시 v5 점수 차 피해·장수 생존·12/14/16 정원을 사용한다. 사이트와 서버 규칙 게시 및 [배포 검사](https://github.com/mathtjungsw/samguk-together/actions/runs/40616648980)가 성공했고 전체 채팅에 안내했다. 11:00·12:00 실제 시각의 전환은 아직 관측하지 않았다. 아래 시즌 전환 최초 배포 기록의 v4 설명은 그 당시 이력이다.

한국시간 2026-10-28 기준으로 테스트 시즌은 11:00에 종료하고 시즌 1은 12:00에 개막한다. 이번 배포는 시즌 전환만 포함하며 전투·도시 정원은 기존 v4 규칙을 사용한다. 새 전투 규칙은 별도 구현·설명서·대조표 단계의 대상이다.

- `worlds/main`: 테스트 시즌. 서버 시간 11:00부터 쓰기를 거부한다. 종료 시점까지의 충원과 미완료 관평 기본 선택을 결정적으로 정산한 결과를 지난 역사 화면에 표시한다.
- `worlds/season-1`: 시즌 1. 서버 시간 12:00부터 초기 생성·참가·행동을 허용한다. 기존 군주 전적·점령 영토·주둔 병력·장수·재참가 대기를 가져오지 않는다. 첫 참가 때 군주 이름을 정하고 무작위 영토에서 시작한다.
- `chat/global`은 테스트 시즌이며 11:00부터 쓰기를 거부한다. `chat/season-1`은 12:00부터 사용하는 별도 채팅이다.
- ‘삼국지 지난 역사’에는 최종 랭킹(영토·병력·처치·전사)과 최종 지도만 표시한다. 원본 테스트 전장은 복구와 정확한 정산을 위해 읽기 전용으로 보존하며 삭제하거나 새 전장으로 덮어쓰지 않는다.
- 구버전 화면도 종료 후에는 서버 쓰기가 거부된다. 새 화면은 종료 시 최종 기록 화면으로 바뀌고 12:00부터 시즌 1 접속으로 전환한다. 시즌 1 전장 자료는 첫 접속에서 원자적으로 생성되며 12:00 이전 생성은 차단한다.
- 서버의 시간 조건으로 작동하므로 사용자의 PC나 예약 작업이 실행 중일 필요가 없다. 화면 전환은 접속 중 매초 확인하며 실제 행동 허용 경계는 서버가 결정한다.

규칙 생성: `node tools/generate-season-rules.mjs`. 이전 규칙은 `tests/fixtures/protocol4.rules.json`에 보관한다. 인증·인접·소유권·병력 보존·명령 리비전 검증은 유지하고 시즌 시간과 전장·채팅 경로만 나눈다.

검증: 규칙 단위 검사에 정확한 11:00/12:00 경계·기록 축약·초기화 분리를 추가했고, Firebase 에뮬레이터에서 테스트 시즌 종료 후 쓰기 거절·기록 읽기 허용·개막 전 생성 거절·개막 후 참가와 시작을 확인한다. PC와 휴대폰의 최종 지도/랭킹 및 시즌 1 복귀 화면을 별도로 확인한다.

배포 시 기존 운영 데이터를 가져오기로 덮어쓰지 않는다. 11:00 이후 테스트 시즌 쓰기를 다시 허용하는 롤백은 최종 결과를 바꿀 수 있으므로 하지 않는다. 문제 발생 시 과거 기록은 그대로 둔 채 화면 또는 시즌 1 경로를 수정한다.

## 배포 확인 기록

2026-10-28 한국시간 10시대에 시즌 전환 규칙을 Firebase 콘솔에 게시하고, 사이트 배포 `fcfe01a`의 [GitHub Actions 성공](https://github.com/mathtjungsw/samguk-together/actions/runs/40613816992)을 확인했다. 사이트에 11:00 종료·12:00 개막과 ‘삼국지 지난 역사’ 버튼이 표시되고 기존 테스트 전장이 정상 연결되는 것을 확인했다. 전체 채팅에도 시즌 전환 안내를 한 번 전송했다.

시즌 전환 배포본의 단위 검사 197개·Firebase 검사 54개가 통과했고, 로컬 시간 시나리오로 PC/390px 휴대폰의 종료 화면과 새 시즌 복귀를 확인했다. 미래의 11:00·12:00 운영 전환 결과를 이미 관측했다는 의미는 아니다. 전투 개선 v5는 별도 개발 브랜치에만 구현되어 있으며 이 배포에는 포함하지 않았다.

후속 보완 `ae74948`에서 기존 v4 공격·충원 버튼의 버전 검사를 바로잡았다. PC·390px 로컬 공격과 결과 확인을 통과했고 [최종 배포 CI](https://github.com/mathtjungsw/samguk-together/actions/runs/40614655799)의 테스트·빌드·게시가 모두 성공했다. 게시 후 운영 화면에서 기존 군주/전장 연결과 정상 목적지 선택 안내를 확인했다. 운영에서는 시험 공격을 실행하지 않았다.

## 지난 역사 오류 수정 — 2026-10-28
