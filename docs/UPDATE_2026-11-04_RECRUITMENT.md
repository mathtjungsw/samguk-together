# 시즌6부터 충원 확률·이름 없는 D6 부장

## 변경 내용

- 운영 메타데이터 조회로 현재 시즌5 진행 중임을 확인했다. 시즌5에는 충원 정책을 추가하거나 변경하지 않는다.
- 새 시즌 생성 공통 함수가 시즌6 이상에 `season.recruitmentVersion=2`를 기록한다. 웹·서버·AI 시즌 개막 경로가 같은 함수를 사용한다.
- 정책 없는 저장은 기존 확률/소진 규칙을 유지한다. 기존 전장을 시즌 번호만 보고 소급 변경하지 않는다.
- 새 정책은 D4 90% / D6 7% / D8 2.2% / D12 0.8%. D6 소진 시 이름 없는 D6 부장, D8/D12 소진 시 D4 지급이다.
- D6 익명 병력은 기존 `legacy:true` 표현과 공용 초상을 재사용한다. 고유ID·특기·인연은 없고 고유 명단 예약을 점유하지 않는다. D6 보유 수·이동·강화에는 기존 등급 규칙을 적용한다.
- 포획은 현재와 같이 이름 있는 무장만 가능하다. 보상권·시작 보너스는 변경하지 않는다.
- 내정 보정은 기존 증가량/중첩 규칙을 유지한다. 규칙창과 명단 소진 안내는 현재 전장 정책을 표시한다.
- 반복 DB 조회·타이머·추가 이미지 요청·상시 서버 자원을 추가하지 않는다.

- Firebase 에뮬레이터113개 통과(기존111 + 신규2). 정규 충원의 서버 트랜잭션 저장/재접속/재처리와 사용자 정책 위조 거부를 확인했다. 합계531개 통과.
