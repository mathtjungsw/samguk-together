# 강화 재료 대기 제한 해제

사용자의 직접 변경 지시에 따라 현재 시즌부터 강화 재료의 행동·이동 대기 제한을 해제한다. 구현·단위 검증 완료, 서버 검증·배포 진행.

- 기본 재료 자동 선택과 서버 검사에서 D4 readyAt 제한을 제거했다. 같은 도시의0강D4, 강화 대상 제외,중복 제외,필요 수량과 최소 잔류 조건은 유지한다.
- 보조D6·D8·D12도readyAt/moveReadyAt와 관계없이 소모할 수 있다. 대상/기본 재료와 중복 사용은 금지한다.
- 강화 대상 자체의 기존 행동·이동 대기, 전투 잠금, 실패 한도, 성공률,재료 소모량과 성공/실패 처리·통계는 유지한다. 살아남는 병력과 도시의 대기를 단축하지 않는다.
- 재료 화면 문구를 실제 처리와 맞췄다. 포로 몸값·등용 비용과 군주 부활의 재료 규칙은 이번 강화 변경 범위가 아니다.
- 단위386개 통과. 대기 중D4 성공/실패 소모·동일 요청 중복 방지,대기D6/8/12 보조재료·성공률 유지,강화D4 제외·대상 대기/도시 잠금 유지,화면 실행 가능 상태를 검증했다.
- 실제Firebase Admin 저장 경로의 대기 재료 강화와 같은 요청 재실행을 에뮬레이터로 검증한다. 운영에서 강화/재료 소모 테스트는 하지 않는다.

새 DB조회·서버 사양 변경은 추가하지 않는다. 실제 모바일 조작은 직접 확인하지 못하며 공개 파일의 최신 코드와 안내·서버 배포를 검증한다.
