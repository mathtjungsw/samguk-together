# 비밀 임무 삭제 · 2026-11-02

사용자 요청: 버그가 생기는 비밀 임무 기능 전체 삭제.

- 목표 카드와 전용 탭, 임무 조회·선택·교체·완료 보상 신규 발급을 제거한다.
- 오래된 탭의 임무 요청도 DB 조회 전에 거절한다. 오래된 임무 대기 요청만 기기 저장에서 해제하고 다른 미확인 명령은 보존한다.
- 기존 목표 원본은 복구 불가능하게 지우지 않고 모든 클라이언트 읽기·쓰기를 차단한다. 신규 저장·조회·완료 판정은 없다.
- 이미 얻은 장수와 발급 확정 보상권, 전적·병력·영토·시즌 상태는 유지한다. 기존 미수령 임무 보상은 일반 기존 보상으로 영토·명령에서 수령할 수 있다. 토벌 보상도 같은 위치다.
- 포로·몸값·강제등용·탈출·인연·강화·200명 명단은 유지한다.

검증·배포 결과는 작업 완료 시 갱신한다.
