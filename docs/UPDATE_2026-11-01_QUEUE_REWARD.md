# 공격 저장 오류·D12 보상·AI 4시간 간격

## 보상 수령 후속 오류 수정

사용자가 보상 수령 시 ‘다시 시도’를 보고했다. 사용권은 미사용이고 무장20명 후보가 남아 있으며 전 도시의 순수 수령 계산은 정상이었다. 새 Admin SDK 인스턴스의 트랜잭션이 로컬 캐시가 비어 첫 콜백에 null을 주면 기존 코드는 즉시 중단했다. 전황 변경 때문이라는 안내가 실제 원인을 가렸다.

실제 Admin SDK를 격리 Firebase 에뮬레이터에 연결해 기존 방식의 중단을 재현했다. 대상 전장 하나의 읽기가 준비될 때까지 제한된 구독을 유지한 뒤 원자 수령하고 즉시 해제하도록 수정했다. 실패·없어진 전장·15초 읽기 제한에도 해제한다. 최초 수령 성공·재시도 중복 없음·인증 및 티켓 보호를 검사했다. 화면이나 AI 규칙은 바꾸지 않는다. 단위294개·서버 SDK/규칙 집중4개 통과. 운영 재배포 및 지급 상태 확인 결과는 아래 기록에 추가한다.

사용자 실행 지시: 오류 수정, 재발 방지, 김현성(본) 군주 D12 랜덤권 1장, AI 내부 등장 4시간 간격. 보상 방식은 사용자 답변으로 ‘D12 무작위 1명 랜덤권’ 확정.

## 구현 내용

- 복귀 대기 장수는 명령 처리 중 빈 도시에 돌아올 수 있다. 기존 서버 규칙이 이때 개인 이동 대기 갱신을 거절하여 공격 전체를 취소했다. 실제 사본의 시상→여강 공격에서 수정 전 실패·수정 후 성공을 확인했다.
- 실제 대기열의 동일 병력이 원래 소유자 도시로 복귀하는 경우에만 대기 변경을 허용한다. 기존 대기보다 줄이지 않고 실제 도착 시점+10분 이상을 유지한다. 자동 복귀가 현재 명령보다 앞선 충원 정산 시각에 일어나는 경우도 허용한다. 이름·ID·등급·소유권·원본 위치 검사는 유지한다.
- 공격·충원·다른 군주의 명령 중 복귀 상황 및 대기 단축·타인 도시·허위 출처를 거절하는 회귀 검사를 추가했다.
- AI 내부 등장 주기는4시간으로 변경한다. 시작 AI 수1~5, 10분 판단, 국가15영토·내부 도시 조건은 유지한다. 과거2시간 회차는4시간 회차로 한 번 환산하여 중복 등장이나 과도한 대기를 막는다. 시즌 개막 기준4시간 경계이며 예약 실행 시 반영된다. 보복 평가의 기존2시간 창은 별도로 유지한다.
- 운영 표시 이름 ‘김부장(본)’과 UID를 확인한 대상에게 고정 ID의 D12 랜덤권1장만 지급한다. 지급 도구 재실행으로 늘어나지 않는다. 운영 데이터의 공격·무장 추첨은 대신 실행하지 않는다.
- 본인 군령 상단 ‘D12 보상 랜덤권’에서 자신의 도시를 선택한다. 현재 전장에 없는 D12 중 서버 난수로1명을 받고, 포화 도시는 D4 한 명을 소모한다(전사 집계 제외). 무장은10분 대기한다. 미등장 D12가 없거나 수령 조건이 맞지 않으면 사용권을 보존한다.
- 보상 티켓은 본인만 읽고 서버만 발급·소모한다. 전장 트랜잭션에 영구 수령 증빙을 함께 기록해 동시 클릭·실패 후 재시도에도 중복 수령을 막는다. 무장 중복은 기존 heroIndex로 검사한다.
- 원본 전장·병력을 보존한다. 보상 조회는 본인의 작은 경로만 구독하며 전체 전장은 수령 요청 시에만 처리한다. 새 수령 함수는 최소 실행 수0으로 상시 대기 비용을 추가하지 않으나 호출에 따른 비용은 발생할 수 있다.

## 검증·배포 결과

- **구현·검증·배포·보상 지급·전체 공지 완료.** 단위293개와 Firebase 규칙91개, 합계384개 통과. 실제 운영 사본의 시상→여강 공격 저장도 에뮬레이터에서 성공했다. 운영 공격이나 대신 보상 추첨은 하지 않았다.
- 코드 `8e6d4e3`, [GitHub Actions](https://github.com/mathtjungsw/samguk-together/actions/runs/41261423452) 검사·Pages 배포 성공. 운영 화면 자산 `app.js?v=d4069f266380`에 보상 버튼·새 릴리스·인증 수령 호출이 포함됨을 내려받아 확인했다.
- Firebase 규칙245,346 bytes 게시 성공. 기존5개 함수 업데이트와 `rulerReward` 신규 배포 성공. 외부 인증 없는 수령 호출은401로 거절하고 CORS 사전 요청은204로 응답함을 확인했다. 기존 보복 평가2시간 창을 보존한 최종 AI 함수도 재배포했다.
- 운영 시즌4에서 메타데이터 적용 revision1465, `spawnIntervalMs:14400000`, 환산 회차8을 확인했다. ETag 조건부 저장으로 동시 사용자 명령 덮어쓰기를 막고 영토·병력·복귀대기·무장 인덱스·보상 증빙이 전부 보존됨을 검사했다. 이는 전투나 초기화를 실행하는 작업이 아니다.
- 김부장(본) 군주의 `compensation-20261101-attack-d12` 티켓은 D12·미사용1장 상태로 지급됐다. 동일 지급 도구 재실행은 기존 티켓을 반환해 추가 지급하지 않았다. 최종 확인 때도 미사용 상태였다.
- `update-20261101-queue-reward-4h`가 운영 release와 전황에 적용됐으며 전체 채팅에는 해당 공지가 정확히1개였다. 새 화면 접속자는 기존 접속 알림 방식으로 안내받는다.
- 브라우저 제어가 현재 앱 설정에서 비활성화되어 실제 화면 클릭·모바일 배치 검증은 하지 못했다. 빌드·배포 자산 검사와 서버 검증을 화면 실물 검증으로 표현하지 않는다. 실물 무장 추첨은 대상 군주에게 남겨두었다.
