# 2026-11-02 병력 강화·AI 일반 공격 조건

적용 대상: **시즌5부터**. 현재 시즌4의 전투·AI 공격 기준·병력과 과거 시즌 결과는 유지한다. 시즌을 강제로 끝내거나 초기화하지 않는다. 새 시즌 생성 시 강화 정책1·AI 공격 정책2를 함께 기록한다. 이 문서는 배포 확인 후 완료 기록으로 갱신한다.

## 병력 강화

- D4·D6·D8·D12·D20 모두 최대+3. 기본 주사위 최소 눈을 강화당1 올린다. 범위 내 정수는 동일 확률이다. D4+1은2/3/4, +3은4 고정이다. 전투 특기에 의한 최종 보정은 별도로 적용한다.
- +1/+2/+3 시도 성공률은80/60/40%. 같은 도시의 행동 가능한0강 D4를 기본 재료로 소모한다.

- 보조 재료는 같은 도시의 다른 D6·D8·D12 중 수동으로1명 선택한다. 각각+10/20/30%p, 상한100%. 이름 있는 장수도 소모되므로 이름·등급·강화 상태와 소모 안내를 먼저 표시한다.
- 성공·실패 모두 재료를 소모한다. 실패는1단계 하락(최저0)하고 누적 실패+1. 성공해도 누적 실패는 남는다. 한도 도달 시 대상이 전사한다. D20도 동일하며 영토는 보존하고 기존 군주 부활을 이용할 수 있다. 부활·새 충원은0강/실패0이다.
- 도시 행동 소모와 강화 후 새 대기는 없다. 기존 도시·병력 행동/이동 대기는 유지한다. 대상·보조 재료는 기존 대기가 끝나야 한다. 재료와 대상 외에 주둔 병력1명을 남겨 실패 전사에도 빈 도시가 되지 않게 한다.
- 강화 전사만 사망·강화 사망에 집계한다. 재료는 교환 소모이며 전사/적 처치/전투 패배 통계에 넣지 않는다. 이름 있는 장수 소모·전사 시 고유 이름 예약은 풀린다.
- 상단/내 도시/장수 상세에서 강화 창을 연다. 성공률·비용·실패 잔여·이번 실패 시 전사를 표시한다. 병사 강화별 인원, 장수 상태, 전투 결과·전황에도 반영한다. 강화 결과를 전체 채팅으로 매번 보내지 않는다.

## AI

시즌5부터 일반 공격 기준은 사람 상대75%, 중립·AI70%이다. 실제 마지막 공격 이후 매시간5%p, 최대15%p 낮추며 최저60%이다. D20을 보내면90% 기준을 유지한다. 기존 모험 공격, 사람2영토 이하 보호, 방어 병력 확보, 내부 등장4시간·판단10분은 유지한다. AI 자동 강화는 추가하지 않는다.

## 저장 안전·운영

강화는 Google 인증 서버 함수에서 한 전장 단위 원자 트랜잭션으로 처리한다. 서버 비밀키로 순번별 난수를 고정한다. 요청ID·개인 순번과 최근100개 영수증으로 응답 유실/재시도의 중복 소모와 재추첨을 방지한다. 클라이언트는 미확인 요청을 기기에 보관하고 이전 결과부터 확인한다. 오래된 순번은 영수증 정리 후에도 다시 실행하지 않는다.

강화 수치·누적 실패·처리 순번·영수증을 클라이언트가 수정하거나 지우지 못하게 한다. 이동/복귀 시 원본 병력에서 강화 상태가 유지되는지 검사한다. 이전 화면의 시즌5 쓰기는 새 프로토콜을 요구해 차단한다. 시즌4에는 새 프로토콜을 강요하지 않는다.

기존 공통 전황 구독을 재사용하며 강화 전용 주기 조회는 추가하지 않는다. 강화할 때만 서버 함수와 저장이 실행되므로 시도 횟수가 늘면 함수 실행·DB 전송량이 늘 수 있다. 상시 인스턴스0·최대1 설정을 유지하고 한 번의 트랜잭션 동안만 제한된 전장 구독을 유지한다.
