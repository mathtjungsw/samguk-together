# 우승자 AI 수 선택 누락 수정 — 2026-10-30

## 원인

시즌3 종료 화면에서 선택 호출이 Cloud Run 입구의403으로 거부됐다. callable에 브라우저 호출용 invoker 설정이 없었으며, 앱의 빈 catch가 오류를 숨겼다. 화면에는 선택 영역도 오류도 표시되지 않았다.

## 수정

- aiRulerChoice만 public invoker로 설정한다. 함수 내부의 Google 로그인 검증, 우승자 권한, 1~5명 범위와 다음 개막 전 시간 검증은 유지한다. 다른 서버 함수의 접근 범위는 넓히지 않는다.
- 선택 영역에는 로딩·오류·다시 불러오기 상태를 표시한다. 실패 시 빈칸으로 숨기지 않는다.
- 로그인 복원 순서를 보완하고, 이전 요청의 응답이 새 모달·시즌·선택 결과를 덮지 않도록 한다.
- 모바일에서는1~5명 버튼을 한 줄로 배치하고 선택된 수를 강조한다.

단위280개·빌드를 통과했다. 브라우저 요청 사전 검사와 비로그인401 거부를 실제 운영 함수에서 확인한다. Google 로그인한 우승자의 실제 저장 화면은 자동 검사 범위와 구분한다. 사이트 배포 후 공지와 최종 결과를 아래에 추가한다.
