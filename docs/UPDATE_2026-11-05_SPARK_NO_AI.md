# AI 없는 무료 운영 버전

상태: 구현·단위421개/서버119개 및 실제 브라우저 시험 완료. 새 Spark 프로젝트와 인증 계정10개/DB 규칙 준비 완료. OAuth 반환 주소 추가 저장 확인 대기; 최종 이관·사이트 배포·기존 프로젝트 결제 해제 전. 기존 AI 자동 실행은 중지했다.

## 사용자 확정 범위

- AI군주 코드를 복원 가능하게 보관하고 무료 버전을 별도로 개발·배포한다. 11월5일 사전 확인에서 기존 DB 월 누적 다운로드가24,158,528,951bytes(약24.16GB)로 Spark 월10GB를 초과해 있었다. 사용자가 **새 Spark 무료 프로젝트로 이전**을 선택했다. 새 프로젝트는 `samguk-friends-20261105`, 원본은 `samguk-together`다. 자동으로 무료 프로젝트를 순환 생성하는 기능은 만들지 않는다.
- 이번 시즌 기존 AI는 자동 행동만 멈추고 세력·영토·병력을 보존한다. 다음 시즌부터 AI를 생성하지 않는다.
- 사람의 공격/이동/강화, 포로, 무장200명, 인연, 보상, 채팅, 지난 역사와 시즌 규칙은 유지한다. 시즌6부터 충원 정책 변경도 유지한다.

## 구현

- 무료 전장 경로 `sparkWorlds`, `sparkHistoryFeed`, `sparkChat`, `sparkBattleRecords`, `sparkEnhancementRecords`, `sparkRecordVersions`를 사용한다. 기존 AI 전장 경로는 원본으로 보존한다.
- 공통 전투/명령 엔진을 브라우저에서 실행한다. 전장 전체를 다시 저장하지 않고 변경된 도시/군주/기록만 루트 다중경로 update로 원자 저장한다. `baseRevision`과 DB의 실제 revision을 비교해 다른 사용자의 동시 저장과 충돌하면 최신 전황으로 재계산한다. 같은 명령 ID/seq·강화 난수를 재사용한다.
- 강화는 기존 즉시/일괄 큐를 유지하고 변경된 병력과 작은 영수증을 저장한다. 상세 기록은 WebCrypto SHA256 버전의 별도 경로에 같은 update로 함께 저장한다. 전달 대기/outbox가 필요 없는 원자 쓰기다.
- 실시간 변경 구독, 지난 기록의 기기 캐시, 전투 상세 요청 조회, 채팅50개 저장/10개 미리보기 유지. 서버의 중복 전장 읽기·10분 AI 조회·함수/스케줄 실행을 제거한다.
- 신규 등록·이름·시작·공격·이동·관평10초 선택·강화·포로 처우·토벌 보상·기존 D12권을 무료 경로로 연결한다.
- 미접속 충원·확률/확정 탈출·72시간 시즌 종료는 누군가 접속하거나 명령할 때 기존 시간으로 정산한다. 종료1시간 뒤 첫 접속 시 다음 시즌을 한 번만 생성한다. 아무도 접속하지 않은 시각에 별도 서버 작업을 돌리지 않는다.
- 이전 시즌 결과는 무료 전장에 있으면 그쪽, 이전 AI 시절 결과는 원래 경로에서 읽는다.
- AI 시작 인원 선택 UI를 숨기며 기존 AI의 공격/이동·추가 등장·능동 몸값 요청/수락은 실행하지 않는다. 기존 도시의 일반 충원과 공격받을 때 수비 판정은 유지한다.

## 저장 보호와 한계

- Google 로그인, 명령자 UID, 시각·형식·병력 등급·대기 값·도시 ID·전장 revision·시즌 정보 검증을 적용한다. 익명/원본 전장 쓰기·무료 전장 삭제·AI 계정 명령·런타임 변경은 막는다.
- 무료 모드는 친구들의 정상 클라이언트를 신뢰한다. DB 규칙만으로 주사위 결과와 모든 전투 계산의 정당성을 서버처럼 증명하지 않는다. 변조 클라이언트에 대한 완전한 부정행위 방지를 제공하지 않으며 출시용 구조로 설명하지 않는다.
- 전송량은 감소를 목표로 하지만 무료 한도 충족을 보장하지 않는다. Spark DB의 월10GB 다운로드/1GB 저장/동시연결100 제한을 넘으면 이용이 제한될 수 있다. 변경분 저장도 접속자가 받는 데이터 전송을 없애지는 않는다.
- 기존 누적 요금은 요금제 변경으로 취소되지 않는다. 변경 전에 사용한 서비스 요금은 뒤늦게 청구에 나타날 수 있다.

## 복원

[AI 버전 복원 절차](AI_VERSION_RESTORE.md). GitHub 태그/브랜치, 검증된 로컬 Git bundle, 약5MB DB/규칙 사본을 준비했다. 무료 모드 이후 진행을 보존하려면 최신 무료 전장도 역이관한다.

## 검증·운영 기록

완료 후 아래에 실제 결과를 기록한다. 운영 전장에 시험 공격·강화·병력 지급은 실행하지 않는다.

- 11월5일07시 최신 Monitoring 월 누적 표본24.16GB, 저장 약5.05MB를 확인했다. 실제 청구 명세나 AI 단독 기여도는 이 수치로 확정하지 않는다.
- `aiOperations/enabled=false`를 원본 프로젝트에 적용하고 읽기로 확인했다. 이번 시즌 AI 세력·영토·병력과 사람용 함수는 그대로 남아 있다. 전체 무료 이전이 끝났다는 뜻은 아니다.
- 새 프로젝트는 기본 Realtime Database(asia-southeast1), Web App, 표준 Firebase Auth, 기존 UID를 보존한 Google 계정10개를 준비했다. 새 프로젝트에는 결제 계정이 없다. DB 규칙 배포 성공.
- 새 Google 제공업체는 기존 앱의 OAuth 클라이언트를 사용한다. 새 Firebase 인증 도메인의 원본/반환 URI를 추가하도록 입력했고 브라우저 보안 정책에 따른 저장 직전 확인을 요청했다. 기존 주소는 유지하고 Gmail/Drive 등 추가 동의 범위는 요청하지 않는다. 확인 전 저장하지 않는다.
- 격리 Firebase 에뮬레이터에서 단위421개와 서버119개 통과. 가장 최근 변경 후 무료 전장 대상6개도 재검증했다.
- 실제 브라우저에서 **로컬 demo 전장에만** 신규 로그인/이름/무작위 시작, 실제 채팅, D4 두 명 일괄 강화, 중립 공격과 전투 결과창, 새로고침 후 영토2곳·강화·대기 보존을 확인했다. 콘솔 오류 없음. 화면 `playtest/spark-browser-qa.png`.
- 운영 전장에 시험 전투·강화·보상을 실행하지 않았다. 원본 동결/복사, 원본 함수 삭제, 사이트 전환과 결제 해제는 새 실제 Google 로그인 확인 뒤 진행한다.
