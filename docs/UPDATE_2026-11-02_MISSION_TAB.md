# 비밀 목표 전용 탭

상태: 구현·단위 검증 완료, 화면 검증/배포 진행 중. 적용: 현재 시즌5.

사용자의 기존 화면 수정 후속 요청을 현재 수정 범위에 포함했다. 영토·명령 화면에서는 비밀 목표 카드와 보상 도시 선택을 제거한다. 같은 전장 정보 탭 줄에 비밀 목표 탭을 추가하고, 탭을 처음 열 때만 개인 목표를 조회한다. 선택/진행률/완료/보상 수령은 새 탭에서 제공한다. 토벌 D6 보상 수령권도 같은 곳에 남겨 기능을 보존한다. 미확인 명령 복구 버튼은 도시 명령에서도 필요할 때 표시한다.

기존 목표 선택과 진행/수령 기록을 변경하지 않는다. 매초 DOM 재생성을 막는 안정화는 새 탭에도 유지한다. 재방문은 기기 메모리의 목표를 우선 사용하고, 전황으로 계산 가능한 진행률은 공통 전황을 사용한다. 새 주기 DB 조회나 서버 규칙 변경은 없다.

## 검증

- 단위323개: 도시 영역에 목표/보상 조작이 없는지, 별도 목표 영역에 남는지, 미확인 명령 복구를 유지하는지 포함.
- 브라우저 회귀 검사는 기존 안정성8개에 도시 영역 분리/복구2개를 더해 총10개로 확장했다. 실제 앱의 탭 이동/자동 목표 조회/선택/도시 화면 복귀와 모바일 배치를 확인한다.
- 게임 및 서버 배포/공지 결과는 완료 후 추가한다.
