# 지도 세력명 표시 상세 개발계획

상태: **사용자 구현 지시에 따라 구현·검증·배포 완료**. [실제 적용·검증 기록](UPDATE_2026-11-02_FACTION_MAP_LABELS.md)이 아래 계획의 실행 상태와 세부 조정에 우선한다. 대상: 삼국 · 함께 천하(samguk-online).

사용자 확정 요청은 세력마다 대표 영토 한 곳 위에 세력명을 굵게 표시하고, 모든 영토에 반복하지 않는 것이다. 아래 글자 크기·대표 선정·겹침 처리 등은 기존 지도에 맞춘 구현 기본안이다. 사용자에게 추가 결정을 요구할 미정 사항은 현재 없다.

## 1. 이번 범위와 적용 시점

- 현재 진행 중인 전장 지도에 세력명 표시를 추가한다. 이후 사용자의 구현·배포 지시를 받으면 현재 시즌부터 적용할 수 있다. 시즌을 다시 시작할 필요가 없다.
- 사람·AI 모두 보유 영토가 있는 세력에 같은 기준을 적용한다. 세력당 지도 이름은 최대 한 개다. 중립·영토가 없는 군주는 표시하지 않는다.
- 별도 세력 이름을 새로 입력받지 않고 저장된 군주 이름을 그대로 표시한다. 예: 정승원, 김현성(본), AI왕건. 이름 변경도 반영한다.
- 천하 판세와 전쟁 준비 두 지도 모드에 공통 적용한다. 전쟁 준비에서 후방을 흐리게 해도 세력명은 읽을 수 있는 대비를 유지한다.
- 영토 경계·실제 인접 관계·세력색 배정·승패·병력·선택/이동/공격 규칙은 변경 대상이 아니다. 과거 시즌 결과 지도는 별도 표시 구현을 사용하므로 이번 범위에서 확대하지 않는다.
- 비밀 임무는 삭제 상태를 유지한다. 앞선 이전 명령 복구 수정은 이미 배포 완료한 작업이며 이번 계획에 다시 개발 항목으로 넣지 않는다.

## 2. 화면에서 보이는 모습

| 항목 | 계획 기본값 |
| --- | --- |
| 표시 내용 | 세력색 작은 표식 + 군주 이름 |
| 위치 | 대표 영토 안의 기준점 위쪽. 도시 이름·병력 숫자와 분리 |
| 글꼴 | 기존 한글 고딕 계열, 굵기800 |
| PC 글자 크기 | 기본18px, 공간에 따라16~20px |
| 모바일 글자 크기 | 기본15px, 최저13px |
| 글자색 | 진한 먹색 계열. 세력색이 밝거나 추가색이어도 대비 확보 |
| 테두리 | 밝은 비단색 계열의 약3~4px 외곽선 |
| 세력 식별 | 기존 세력색 표식에 얇은 진한 외곽선 추가 |
| 긴 이름 | 최대2줄. 그래도 공간이 부족하면 말줄임, 전체 이름은 접근성 이름과 툴팁에 보존 |
| 기본 표시 | 두 지도 모드에서 항상 켬. 첫 버전에는 별도 설정 버튼을 추가하지 않음 |

SVG 화면 좌표층에서 글자를 그려 확대할 때 영토와 같은 비율로 거대해지지 않게 한다. 배경을 크게 덮는 상자 대신 글자 테두리를 기본으로 사용한다. 세력명은 장식 표시로 취급해 지도 클릭·우클릭·드래그·핀치 확대를 가로채지 않는다. PC에서 영토에 올렸을 때 기존 접근성 설명/툴팁으로 전체 이름을 확인할 수 있고, 모바일에서는 해당 도시 선택 시 기존 군주 정보에서 전체 이름을 확인한다.

## 3. 대표 영토 선정

### 3-1. 기본 대표 영토

1. 각 세력의 실제 소유 영토를 모은다. 저장된 영토 개수 요약만 믿지 않고 지도 소유자를 기준으로 한다.
2. 기존 인접 목록으로 같은 세력의 연결 영토 덩어리를 나눈다. 섬처럼 떨어진 땅이 있더라도 세력명은 전체에서 한 번만 표시한다.
3. 도시 수가 가장 많은 덩어리를 고른다. 동률은 덩어리에 속한 가장 작은 고정 영토ID로 정해 재접속 때도 같은 결과를 얻는다.
4. 그 덩어리의 도시 좌표 평균에 가장 가까운 실제 소유 영토를 대표로 고른다. 동률은 지도 구획 면적이 큰 곳, 고정 영토ID 순으로 정한다.
5. 평균 좌표 자체에 이름을 찍지 않는다. 평균이 바다나 다른 세력 땅에 놓이더라도 실제 대표 영토 안의 기준점에 연결해 표시한다.

기준점은 대표 영토 내부의 도시 좌표를 우선 사용하고, 기존 도시 좌표가 구획 밖인 예외에는 구획 내부점으로 보정한다. 글자 전체 폭이 작은 한 영토 안에 들어가지 않더라도 표식과 기준점은 본인 영토에 남긴다. 글자 위치를 옮겨야 할 때는 짧은 연결선으로 어느 세력 땅을 가리키는지 구분한다. 이름을 잘라서 한 칸 안에 억지로 넣는 방식은 사용하지 않는다.

### 3-2. 확대·이동 중 보조 대표

기본 대표가 화면 밖에 있고 같은 세력의 다른 영토가 화면에 보이면, 보이는 소유 영토 중 화면 중앙에 가까운 곳 한 개에 임시 표시한다. 임시 대표가 계속 화면 안에 있는 동안 유지해 드래그할 때 매 프레임 이리저리 뛰지 않게 한다. 기본 대표가 다시 들어오면 기본 대표로 복귀한다. 보이는 소유 영토가 없으면 그 세력 이름도 화면 밖으로 사라진다.

대표는 군주D20 위치나 현재 병력에 종속되지 않는다. 군주 이동·사망·부활이나 매초 대기시간 변화만으로 이름 위치가 바뀌지 않는다. 소유권이 바뀌면 다시 선정하고, 개명은 글자만 갱신한다. 시즌이 바뀌면 이전 대표 계산을 버린다. 대표 영토 선택은 화면상 표식일 뿐 수도·특수 거점 같은 게임 효과를 부여하지 않는다.

## 4. 도시명·다른 세력명과의 겹침 처리

기존 src/map.js는 도시명과 병력 글자의 위치를 선택하고 충돌하면 일부 도시명을 숨긴다. 여기에 세력명을 그냥 덧붙이지 않고 표시 공간을 함께 계산한다.

배치 우선순위:

1. 현재 선택한 출발/목표 영토의 이름과 병력, 공격·이동 방향 표시.
2. 내 세력명과 현재 사용자가 강조한 세력명.
3. 그 밖의 세력명. 영토 수가 많은 순, 동률은 고정 군주ID 순.
4. 일반 도시명과 병력 글자. 기존 지도 조건에 따라 표시.

세력명은 대표 기준점 위쪽부터 아래·좌우의 제한된 후보 위치를 확인한다. 대표와 동떨어진 다른 세력 땅이나 바다로 크게 밀어내지 않는다. 주변 도시명 공간을 조정하고, 긴 이름2줄/축약, 글자 크기 하한 적용 순으로 충돌을 완화한다. 도시 그림과 선택 테두리, 주요 조작 표시는 유지한다.

휴대폰 전체 지도처럼 여러 세력이 아주 좁은 지역에 몰리면 모든 이름을 동시에 완전히 표시하는 것은 보장하지 않는다. 위 방법으로도 읽을 공간이 없을 때만 낮은 우선순위의 세력명을 임시 숨기고 대표 영토의 작은 세력색 표식은 남긴다. 확대하면 공간을 다시 계산해 이름을 복구한다. 확대 상태에서도 세력당 이름은 하나만 그린다. 내 세력이나 강조한 세력 이름은 먼저 공간을 확보하고, 화면 경계에서는 글자 잘림을 피하도록 후보 위치를 재선택한다.

## 5. 기술 구성과 비용

| 파일 | 계획 작업 |
| --- | --- |
| src/faction-labels.js (신규 예정) | 연결 덩어리·대표 영토·안정적인 정렬/배치 후보 계산을 순수 함수로 분리 |
| src/map.js | 기존 지형·도시와 구분한 세력명/표식층 추가, 도시 글자와 충돌 정보 공유, 확대·이동·크기 변화 반영 |
| public/map-style.css | 굵은 글씨·테두리·세력색 표식·PC/모바일 크기 정의 |
| tests/faction-labels.test.mjs (신규 예정) | 대표 선정과 표시 수, 경계 조건의 회귀 검사 |
| README.md 등 | 구현 완료 후 실제 표시 규칙과 적용 기록 갱신 |

현재 내려받는 players의 이름·세력색, territories의 소유자, 로컬 지도 좌표와 인접 목록으로 계산한다. 대표 위치를 서버에 저장하지 않으며 새 Firebase 경로·조회·함수·외부 자산을 추가하지 않는다. 이 기능을 위한 DB 전송량 증가는 계획상 없다. 기존 게임 동기화 비용 자체가 없어지는 것은 아니다.

소유권과 이름이 같은 갱신에서는 대표 선정 계산을 재사용한다. 병력·쿨타임·채팅만 바뀌면 세력명 노드를 다시 만들지 않는다. 확대·드래그 중에는 화면 위치와 겹침만 다시 계산하며 한 화면 갱신당 한 번으로 묶는다. 같은 군주ID의 SVG 노드를 유지해 깜빡임을 줄인다. DOM에는 이름을 텍스트로 넣고 저장된 이름을 HTML로 조립하지 않는다.

## 6. 작업 순서

1. 지도 데이터의 좌표·구획·인접 목록을 연결해 대표 선정 계산을 추가한다.
2. 기본 대표와 화면 밖 대표의 임시 표시를 구현하고 세력당 한 개 조건을 검증한다.
3. 별도 SVG층과 글꼴을 적용한다. 선택한 도시 글자·도시 그림·화살표와의 겹침을 조정한다.
4. 두 지도 모드, 모바일/PC, 확대와 드래그, 개명·점령·멸망·재참가·시즌 전환을 확인한다.
5. 단위 검증·빌드와 실제 화면 검증을 진행한다. 이번 변경은 서버 저장/권한을 바꾸지 않으므로 규칙을 임의로 수정하지 않는다. 저장 흐름에 변경이 생긴 경우 해당 서버 검증도 추가한다.
6. 이후 구현·배포 지시에 따른 승인 범위에서 사이트를 배포하고 실제 운영 파일을 확인한다. 완료 후 전체 채팅·전황·접속 알림으로 변경 내용을 안내한다.

## 7. 검증 및 완료 기준

- 사람·AI를 합쳐 활동 세력 수보다 세력명 노드 수가 많지 않다. 같은 세력의 떨어진 땅에 이름이 중복되지 않는다.
- 중립·영토0개는 표시하지 않는다. 소유자 정보가 일시 누락되면 오류 없이 건너뛴다.
- 가장 큰 연결 덩어리와 동률/한 칸/길쭉한 땅/분리된 땅에서 대표가 실제 소유 영토에 놓인다.
- 병력·쿨타임·채팅 변화로 대표가 이동하거나 노드가 깜빡이지 않는다. 점령·개명·시즌 전환에는 갱신된다.
- 기본 대표가 화면 밖인 경우 임시 표시가 최대 한 개 나오고, 다시 화면에 들어오면 중복 없이 복귀한다.
- 이름1자~16자·공백·괄호·AI 이름·특수문자가 안전하게 표시된다. 긴 이름 축약 시 전체 이름을 확인할 수 있다.
- 기본15색·추가색·밝은/어두운 색 모두 먹색 글자와 밝은 테두리의 가독성이 유지된다.
- PC 폭1280/1920, 모바일360/390/430, 기본 확대와200%/400%, 두 지도 모드에서 이름·도시명·숫자·화살표의 겹침과 화면 끝 잘림을 확인한다.
- 여러 세력이 빽빽한 표본에서 축약·최소 글꼴·임시 숨김이 정해진 우선순위를 따른다. 확대 시 숨긴 이름이 돌아온다.
- 세력명 위 클릭도 아래 영토로 전달된다. 같은 영토 재클릭 취소·PC 우클릭 취소·드래그·모바일 핀치 조작이 유지된다.
- 기존 전장 읽기 횟수가 증가하지 않으며 새로운 주기 DB 조회와 서버 저장이 없다.

이 문서는 작성 당시의 상세계획을 보존한다. 사용자 구현 지시에 따른 실제 결과는 위 업데이트 기록에 정리했다.
