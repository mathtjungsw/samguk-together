# 추가 무장50명 초상 · 2026-11-02

사용자의 추가 무장 사진 적용 지시에 따라151~200번50명의 초상을 제작하고 공통portraitHTML에 연결했다. 도감·내 장수·도시 주둔군·출전·포로·전투 결과에서 같은 초상을 사용한다. 기존150명과 이름 없는 병력 표식은 유지한다.

- 신비부터 두예까지 명단 순서로10열×5행. 게임을 위한 창작 해석이며 OpenAI 내장image_gen/이미지 생성 스킬로 제작했다.
- 원본1774×887px를WebP로 인코딩(88품질,516,864바이트).50개를 개별 요청하지 않고 같은 정적 파일을 재사용한다. Firebase DB 저장/조회는 추가하지 않는다.
- 배포 자산은public/assets/portraits-151-200.webp. 제작 프롬프트·명단·도구·출처 정보는licenses/portraits-151-200.json에 기록한다.
- 추가50개 초상과 기존150개 전체가 유효한 이미지 경로인지,50개 위치가 겹치지 않고 명단 순서와 맞는지,기존 병력 표식이 유지되는지 검증했다. 단위382개 통과.
- 생성된10×5 전체 이미지를 확인했다. 실제 모바일 브라우저 조작은 직접 확인하지 못했으며 기존 CSS 스프라이트 표시 방식을 사용한다.
