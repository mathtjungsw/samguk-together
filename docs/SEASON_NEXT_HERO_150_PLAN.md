## 2. 표를 읽는 공통 규칙

- 내정은 자동 내정 담당1명, 전투/생존/호위/승리 보상은 해당 전투의 자동 특기2명 안에 선정돼야 발동한다. 이동은 기동 담당1명이다. 노숙처럼 내정 도착 지원은 도착 도시 내정 담당을 사용한다.
- 표의 ‘전투’는 공격·수비 공통이며 ‘공격/수비’는 해당 방향만이다. 원래 눈은 보정 전 값이다. 인원에는 D4/D20을 포함하며 ‘무장’ 수는 D6/D8/D12다.
- 자기 눈은1~면수. 재굴림은 같은 주사위1회·높은 값. 한 특기 이익8점·진영 이익10점·상대 감점6점 상한을 유지한다. 낮은/높은 눈 동률은 고정ID로 안정화한다.
- 정원/충원 효과는 담당 주둔·행동 가능 상태에서만. 주기 단축은 가장 짧은 하나, 확률 가산은 같은 등급의 가장 큰 하나만 적용한다. D6/D8 가산은 D4에서 차감하며 합계100%를 유지한다.
- 추가 D4는 빈자리만큼, 표에서 명시한 대기 보상 외 미지급분을 적립하지 않는다. 이동/담당 교체로 지급 횟수·준비·성공 대기를 초기화하지 않는다.
- 생애는 해당 병력 개체의 생성부터 전사까지다. 탈출 시 유지, 전사 후 새로 등장한 개체는 새 생애. 일반 장수 탈출은 인접 내 도시 빈자리 또는 D4 비용 교체가 필요하다. 이 경로 없으면 실패한다. 중립전 D20 확정 탈출만 별도 보장이다.
- 일반 장수 접전 생존30%/15%는 기존대로다. 전용 탈출이 성공하면 다시 추첨하지 않는다. 전용 확률 탈출을 시도한 개체의 중복 일반 생존 추첨은 현행과 같은 배제 정책을 유지한다.
- 이동 단축은 새로 부여할 이동/행동 대기에 적용한다. 기존 퇴각/전투 대기를 줄이지 않으며 각 필드의 기존 해제 시각보다 앞당기지 않는다. 장수만 이동할 때 영토 대기는 부여하지 않는 현행 예외를 유지한다.
- 효과 숫자는 검증 전 추천값이다. 구현 시 실제/미리보기/승률/설명과 맞추고 표본 비교 후 조정 내용을 기록한다.
