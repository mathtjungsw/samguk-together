# 강화 대상 대기 제한 해제

사용자 직접 변경 지시로 대상도 행동·이동 대기와 관계없이 강화할 수 있도록 구현했다. 구현·검증·서버/사이트 배포·전체 공지 완료. 현재 시즌5부터 적용.

- 강화 대상의readyAt/moveReadyAt 사전 제한을 제거했다. D4·D6·D8·D12·D20 모두 적용한다.
- 성공/실패 후 대상과 살아남은 병력·도시의 기존 대기를 단축·연장하지 않는다. 새로운 대기도 부여하지 않는다. 강화 실패 한도에 따른 전사는 기존과 같다.
- 같은 도시·재료 중복 금지·최소 주둔·전투 잠금·시즌 종료·최대3강과 재료비/확률 검증은 유지한다. 공격/이동 중 관평 호위 선택으로 잠긴 도시는 강화할 수 없다.
- 화면 안내는 대상/재료 모두 대기 중 사용 가능,기존 대기시간 보존으로 수정한다. 앞선 재료 대기 제한 해제도 유지한다.
- 단위390개 통과. 전5등급 대상의 행동/이동 대기 중 성공·실패 및 남은 대기시간/도시 대기 보존·동일 요청 재처리 안전성을 검증했다. 서버Admin 트랜잭션도 대상·재료가 모두 대기 중인 조건으로 검증한다.
- 운영에서 임의 강화를 수행하지 않는다. 기존 병력·강화·재료를 소급 변경하지 않고 현재 시즌부터 적용한다. 실제 모바일 조작 대신 화면 HTML·규칙·공개 실행 파일을 검증한다.
