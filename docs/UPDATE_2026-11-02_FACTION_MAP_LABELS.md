# 지도 세력명 표시 · 2026-11-02

상태: 구현·단위/지도 렌더링 검증 완료, 배포 진행 중. 사용자 승인 시안과 상세계획에 따른 현재 시즌 화면 개선이다.

## 구현

- 사람·AI 각 세력마다 가장 큰 연결 영토 덩어리의 중앙에 대표 영토를 잡고 이름을 한 번만 표시한다. 기본 대표가 화면 밖이면 보이는 소유 영토 한 곳에 임시 표시한다.
- 굵은 먹색 이름·밝은 테두리·세력색 점 표식을 사용한다. PC18/16px, 모바일15/14/13px, 최대2줄·말줄임으로 배치한다.
- 선택한 출발/목표 도시와 전쟁 준비의 화살표를 보호한다. 세력명을 먼저 배치하고 일반 도시 그림/글자는 남은 공간에 표시한다. 가려진 일반 도시는 기존 작은 지도 점과 영역 선택으로 접근할 수 있다. 빽빽한 곳은 일부 세력명 대신 표식을 남기고 확대 시 다시 계산한다.
- 병력/시간/채팅만 바뀌면 대표 선정과 SVG 군주 노드를 재사용한다. 소유권·이름·시즌이 바뀌면 갱신한다.
- 지도 지형·연결성과 서버 게임 상태를 바꾸지 않는다. 천하 판세·전쟁 준비 공통 적용이며 지난 역사 지도에는 새 세력명을 넣지 않는다.
- 세력명은 마우스/터치 이벤트를 가로채지 않는다. 영토 접근성 이름과 툴팁에 전체 군주 이름을 유지한다.
- 추가 DB 경로/조회/주기 작업/저장은 없다. 기존 배포 공지 식별자와 생성 규칙만 함께 갱신한다.

## 검증

- 단위347개 통과. 신규11개는 연결 덩어리·동률·누락 군주·오목 구획과 실제90개 구획 내부점·단순 시간 갱신·대표 복귀·충돌/화면 경계·긴 한글/이모지·밀집 우선순위·확대 시 복원 검증이다.
- tools/qa-faction-map.mjs는 실제 TerritoryMap/D3를 linkedom DOM에서 실행하고 SVG를 resvg로 PNG 렌더링한다. 검증 도구의 선택 설치는 playtest/faction-qa-runtime 안에만 있으며 배포 의존성을 늘리지 않는다.
- PC1280/1920, 모바일360/390/430의 천하 판세/전쟁 준비와1·2·4배 사례를 렌더링해 대표 이름·선택 도시·화살표·잘림을 눈으로 확인했다. 5개 세력 표본에서 화면에 보이는 세력명이 중복 없이 표시됐다.
- DOM 노드 유지, 안전한 텍스트, 링크 클릭/우클릭 취소 이벤트의 모의 전달, 장식층 이벤트 차단 속성, 역사 지도 이름 비표시를 자동 확인한다.
- Work의 로컬 브라우저 사용이 비활성화되어 실제 브라우저의 드래그·핀치 제스처와 전체 앱 화면은 직접 검증하지 못했다. 위 결과는 실제 코드의 오프라인 DOM 실행·SVG 렌더링 검증이며 브라우저 조작 검증으로 계산하지 않는다.
- 사이트 번들 생성 성공. Firebase 규칙/서버 검증과 배포 결과는 완료 후 추가한다.
