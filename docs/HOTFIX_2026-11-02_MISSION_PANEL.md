# 비밀 목표 화면 반복 갱신 수정

상태: 구현·대상 검증 완료, 배포 진행 중. 현재 시즌5부터 즉시 적용.

도시 명령 패널은 충원/행동 시계를 표시하려고 매초 HTML을 다시 만들었다. 비밀 목표와 보상 선택도 같은 영역에 들어 있어 동일한 카드까지 재생성되었다. 카드 영역과 도시 본문을 분리하고, 마지막 원본 HTML과 비교해 실제 내용이 바뀔 때만 해당 영역을 갱신한다. 타이머만 바뀌면 카드·버튼·선택칸은 같은 DOM으로 연결된 채 유지한다. 실제 목표 선택/달성/보상 변화와 도시 선택 변경은 반영한다. 원래 패널 스크롤·담당 설정 보존도 유지한다.

오래된 브라우저 탭이 새 공지를 받은 후 자기 버전의 공지를 반복 요청할 수 있는 경로도 수정했다. 처리 영수증이 있으면 이미 안내한 것으로 판정해 불필요한 반복 요청을 막는다. 새 전장 전체 조회나 주기 조회는 추가하지 않는다.

## 검증

- 단위322개 통과. 이전 첫 등록 오류의 회귀 검사와 오래된 공지 영수증 인식 검사 포함.
- 실제 브라우저 DOM 검사8개 통과:10회 시계 갱신 중 카드 동일성, 버튼 포커스/연결, 스크롤, 실제 선택 변경, 달성 보상 버튼, 무관한 전황 변경, 보상 도시 값/포커스, 다른 탭 복귀.
- 검증 소스 tests-browser/mission-stability.js, 실행 도구 node tools/serve-mission-regression.mjs → http://127.0.0.1:4193/. 검사 화면은 합성 전장만 사용한다.
- 실제 앱 소스와 격리 저장소를 연결한 화면에서도 비밀 목표 조회/선택·도시 명령을 확인한다. 운영 계정의 목표/영토/병력은 시험 변경하지 않는다.

최종 사이트/서버 배포·공지 결과는 완료 후 추가한다.
