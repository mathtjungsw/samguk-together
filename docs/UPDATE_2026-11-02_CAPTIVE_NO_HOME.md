# 포로 탈출 후 복귀 영토 없음 · 전사 처리

사용자 직접 변경 지시로 현재 시즌부터 적용한다. 구현·단위 검증 완료, 서버 검증·배포 진행.

- 확률 탈출과2시간 확정 탈출 시 원래 소유 군주의 영토가0곳이면 포로를 제거하고 전사 처리한다. 원래 군주의 전사 수만1 증가하며 포획자의 처치·처형 수를 올리지 않는다.
- 해당 무장의 생존 색인도 해제해 이후 충원/보상 등의 기존 추첨에서 다른 군주에게 다시 등장할 수 있게 한다. 전사한 개체를 이전 강화/실패 누적과 함께 부활시키지 않는다.
- 탈출 전에 원래 군주가 영토를 다시 얻었으면 정상 복귀한다. 영토는 있지만 정원이 찬 상황은 복귀 대기로 보존한다. 포획자 멸망에 따른 석방과 수동 석방은 기존 규칙을 유지한다.
- 기존에 이미 복귀 대기로 보존된 장수를 소급 삭제하지 않는다. 새 정산에서 탈출하는 포로에게 적용한다. 시즌 종료 뒤에 포로를 새로 정산하지 않는다.
- 중복 정산·반복된 같은 강화/전투 요청에서 포로 전사가 중복 집계되지 않게 한다. 포로 탭과 전체 공지에 새 조건을 표시한다.

단위389개 통과. 확률/확정 탈출·영토0 전사,1회 통계·다른 군주 처치 수 유지·색인 해제/다른 소속 재등장 가능,정원포화 복귀 대기·영토 보유 시 복귀를 검증했다. 실제Admin 트랜잭션의 저장/동일 요청 재시도도 에뮬레이터로 검증한다. 운영 전장에서 임의 포로 처형·탈출·공격 테스트를 하지 않는다.
