# 강화 창 밀도·스크롤 개선 · 2026-11-03

사용자의 ‘구현, 배포해줘’ 요청에 따른 UI 개선이다. 직전 개선안의 상세 실행 범위를 아래와 같이 확정하고 구현했다. 게임 규칙/저장 구조는 변경하지 않는다.

## 변경과 검증 기준

- 병력 선택과 별도 강화 상세 카드의 중복을 제거한다. 각 병력 칸 안에 체크박스·이름/등급·현재/다음 단계·주사위 범위·누적 실패·성공률·보조재료를 표시한다. 실패 시 전사 경고는 선택 칸에 즉시 보인다.
- PC는2열,600px 이하 모바일은1열이다. 전역 `.enhancement-modal label`의 큰 여백/블록 표시가 병력 선택에 덮어쓰던 문제를 구체적인 강화 창 스타일로 해결한다. 일반 칸은52px 기준으로 줄이고 선택한 칸에만 보조재료를 표시한다.
- 상단은 제목·도시 선택·간단한 저장 상태로 줄인다. 자세한 규칙과 최근 결과는 접어서 제공하며 최근 결과 요약에는 성공/실패/전사 수를 표시한다. 전체 결과·기존 버전 미확인 요청 복구·같은 결과 재저장 버튼을 유지한다.
- 강화 창은 상단/내용/하단의 세 영역이다. 가운데 내용만 스크롤하며 총 선택 수·기본/보조 재료비·검증 오류·강화 버튼은 항상 하단에 남는다. 중첩 목록 스크롤과 모달 외부 스크롤을 제거한다.
- 병력 체크/보조재료 변경·시계/서버 상태 갱신 시 내용 스크롤과 펼친 도움말/결과·입력 포커스를 복원한다. 다른 모달의 높이/배치에는 적용하지 않도록 `data-kind=enhancement`로 한정한다.
- 로컬 즉시·연속/일괄 강화, 기기 저장 대기·서버 묶음 확정·재시도·병력 명령 잠금/채팅 허용·확률/재료비/대기/전사 규칙은 모두 유지한다. 새 API·DB 반복 조회·상시 서버는 추가하지 않는다.

## 확인한 화면

이번에는 브라우저 연결이 가능해, 운영 전장과 분리한 합성16명/선택3명 데이터로 실제 렌더링을 확인했다. 동일한 생산용 enhancementHTML과 전체 CSS를 사용한 로컬 검증 페이지다. 운영 병력에 시험 강화/공격/이동을 하지 않았다.

- 1024×768: 목록2열(각395px), 모달840×691px, 하단 버튼42px, 버튼아래716.8px로 화면 안에 유지. 모달 바깥 스크롤 없음.
- 390×844: 목록1열(약342.8px), 하단 버튼아래799.4px로 화면 안에 유지. 가로 넘침/모달 바깥 스크롤 없음.
- 320×568: 버튼아래534.5px, 가로 넘침/모달 바깥 스크롤 없음.
- 체크 추가 후 ‘선택4명 / 기본D4 4명’ 갱신 확인. 임시 뷰포트 설정은 검증 후 해제했다.
- 화면 기록: playtest/compact-enhancement-ui-pc.png / playtest/compact-enhancement-ui-mobile.png. 실제 서버를 사용하는 강화 저장 속도나 실기기 터치 환경을 측정한 것은 아니다.

## 검증·배포

단위411개 통과. 선택/보조재료가 같은 칸에 표시되는지, 별도 상세 카드 제거·고정 하단 구조, 전사 위험과 복구/재전송/최근 전사 결과가 유지되는지 회귀 검증을 추가했다. 서버·사이트 배포/전체 검증/공지 확인은 완료 후 추가한다.
